# 📈 Marketing Campaign Response Prediction using Machine Learning

A professional Flask web application that predicts whether a customer is likely to respond to a marketing campaign using a Machine Learning model.

---

## 🚀 Project Overview

This application allows users to enter customer information and receive an instant prediction indicating whether the customer is likely to respond to a marketing campaign.

The model was trained using Scikit-learn and deployed using Flask.

---

## 📊 Input Features

The application accepts the following customer information:

- 💰 Income
- 👶 Kidhome
- 🧑 Teenhome
- 📅 Recency
- 🍷 Amount Spent on Wines (MntWines)

---

## 🎯 Prediction

The application predicts:

- **1 → Customer Will Respond**
- **0 → Customer Will Not Respond**

If supported by the model, a prediction confidence score is also displayed.

## ▶ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Marketing_Campaign_Response_Prediction.git
```

Navigate into the project:

```bash
cd Marketing_Campaign_Response_Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000/
```
